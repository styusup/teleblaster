Telegram Blaster By VibeTool.Club
=================================

CARA PAKAI (tidak perlu install apa pun):

1. Extract / unzip file ini.
2. Double-click "TelegramBlaster.exe".
3. Saat pertama jalan:
   - Masukkan kunci lisensi dari vibetool.id (sekali saja).
   - Jika diminta, isi API_ID & API_HASH dari https://my.telegram.org/apps
     (sekali saja, otomatis tersimpan).
4. Aplikasi langsung berjalan.

Catatan:
- File .exe ini sudah berisi semua dependensi (Python, Tcl/Tk, Pyrogram, dll).
  Tidak perlu install Python atau library apa pun.
- Saat pertama dijalankan, Windows mungkin menampilkan peringatan
  SmartScreen ("Windows protected your PC"). Klik "More info" lalu
  "Run anyway" untuk menjalankan.
- Antivirus kadang menandai aplikasi PyInstaller sebagai mencurigakan
  (false positive). Tambahkan ke pengecualian bila perlu.
- Data (sessions, members.csv, dll) tersimpan di folder yang sama dengan
  lokasi tempat .exe dijalankan.
